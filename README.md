# Telco-Customer-Churn
Predicts which telecom customers are likely to leave, using a Random Forest model.

**Dataset:** Telco Customer Churn (Kaggle), about 7,000 customers
**Tools:** Python, pandas, scikit-learn
**Result:** 79% accuracy

**Key findings:**
- Tenure, monthly charges and total charges are the top churn drivers
- Fiber optic customers and electronic check payers show higher churn
